LOCAL · NO AI
Activity frequencyOnly when resting. Pauses while the window is hidden.

Calm: roughly every 36–64 seconds. Lively: every 14–26 seconds of idle time. Reading, eating and drinking use lightweight, reusable 3D props. Selecting Idle interrupts any activity.

Local personality behaviorOptional deterministic activity selection. No AI model, screen access or network traffic.
Behavior stateLocal rules · balanced

Personalities change which existing activities are selected and how frequently similar actions repeat; they do not enable autonomous AI, external integrations, or desktop observation. Turning this off restores classic seeded choices. Selecting Off above disables all automatic activities.
